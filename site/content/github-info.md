### Quick Tips

- After editing agentic workflow files, always run `gh aw compile` to keep lock files in sync ([source](https://github.com/github/gh-aw/blob/main/.github/aw/workflow-editing.md)).
- Use safe outputs for all GitHub writes in agentic workflows ([source](https://github.com/github/gh-aw/blob/main/.github/aw/workflow-constraints.md)).
- For workflow patterns and best practices, see [GitHub Agentic Workflows](https://github.com/github/gh-aw/blob/main/.github/aw/github-agentic-workflows.md).
- For curated Copilot workflow examples, visit [Awesome Copilot Workflows](https://awesome-copilot.github.com/workflows/).
